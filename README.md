# KinalApp
* **

KinalApp lleva el registro de compra de un usuario, 
desde el producto comprado, precio, hora de compra y
cantidad que compro.

## Tecnologías Utilizadas
* **Java 17**
* **SpringBoot 4.0.2**
* **Maven** (Gestor de Dependencias)
* **MySQL** (Sistema Gestor de Base de Datos)

## Requisitos previos
Antes de ejecutar el proyecto es necesario tener: 
* **JDK 17 o superior instalado**
* **Maven**
* **Una instancia activa de MySQL**
